# BTC AI Predictor 4.0 — DEMO

## Что входит
- `index.html` — интерфейс, Binance WebSocket, автоматическая запись наблюдений в IndexedDB.
- `netlify/functions/kalshi.js` — серверный прокси к публичному API Kalshi.
- `netlify.toml` — настройки Netlify.

## Развёртывание
1. Распакуйте архив.
2. Загрузите содержимое папки `btc_ai_predictor_v4` в новый Git-репозиторий или подключите папку к Netlify через Git.
3. В Netlify выберите Deploy. Netlify должен обнаружить `netlify/functions`.
4. Откройте адрес опубликованного сайта. Проверьте статусы Binance и Kalshi.

## Важные ограничения
- Сохранение сейчас локальное в IndexedDB конкретного браузера/устройства. Для общей истории iPhone + компьютер нужна постоянная БД (например, Supabase) и её ключи/настройки.
- Kalshi API/серия `KXBTC15M` и поля Target могут меняться. Если публичный endpoint не возвращает нужное поле, рынок будет показан, но Target может остаться пустым. Нужно сверить API-ответ с выбранным типом контракта.
- Автоматическое определение результата использует `market.result` со статусом `finalized`/`settled`. Если Kalshi вернёт иной формат, потребуется адаптация.
- Сейчас модель — прозрачная эвристика; она НЕ обученная нейросеть. Система копит размеченные результаты и статистику, но полноценное обучение и честная калибровка вероятностей — следующий этап.
- Снимки каждые 15 секунд одного контракта не являются независимыми ставками. В отчётах их нельзя трактовать как независимые прогнозы.
- Не размещает сделки и не хранит API-секреты.
